LEAD's first question: does this task produce a component?

Yes (a Button, an Input…) → full pipeline, storybook included, STOP for human OK before shipper.

No (an app screen, a config change) → storybook is skipped: spec → builder → reviewer → shipper.

Two STOP points: after spec (approve the contract) and after storybook (approve the render). Everything else runs unattended.

Automation the team does not touch

CI (lint + build-storybook), Chromatic and the Cloudflare Pages branch preview run themselves on every PR. shipper opens the PR and stops; the human merges on GitHub.

Framework: spec → orchestrate → review. The person's value is a fast, honest review — not writing the code.
